# DjangoProjects
Learning Django as part of Lexicon training  

These are two independent projects for practicing Django Web Application Framework  

### 🔬 Focus: Regex URL Routing
In modern Django, we often use simple strings for paths. However, this projects utilizes the older url() patterns to master complex string matching.  

### 🛠️ Tech Stack
*Framework*: Django1.11  
*Language*: Python3.5  
*Frontend*: HTML5, CSS (Basic)  

> [!IMPORTANT]  
> Since this project uses Python 3.5 and Django 1.11 (both of which are End-of-Life), this repository is for educational purposes and practicing regex logic.
